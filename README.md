# Youth Welfare Organization - Donor & Case Management Portal

Live Website for registered NGO.

Features:
- Donor Management with WhatsApp reminders
- Case Management (Medical, Education, Food, etc)
- Fund Allocation Tracking
- Receipts with Finance Secretary Signature
- Public Transparency Page

## Tech Stack
- React (CDN) + Tailwind CSS
- LocalStorage (can be upgraded to Firebase/Supabase)
- 100% Frontend - deployable on Vercel

## Deploy on Vercel
1. Push to GitHub
2. Import in Vercel
3. Deploy

## Local Run
Just open index.html in browser.
